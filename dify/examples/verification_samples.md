# 验证样例与复现指南（会记仇的酒馆老板）

## 1. 重置初始状态
每次重新验证前，执行以下命令即可清空历史恶作剧记忆并将好感度恢复为初始值（`60/100`）：
```bash
python3 backend/app.py --verify
```

## 2. 三回合连续验证步骤

### 样例回合 1：打听传闻（验证 seekdb 混合检索）
- **输入**：`老板，来一杯最烈的麦酒，顺便跟我讲讲迷雾森林的宝藏传闻！`
- **预期表现**：
  - `node_seekdb_search` 检索返回 `lore_01`（迷雾森林的古代遗迹与银鳞龙传闻）；
  - `node_powercontext_recall` 显示暂无恶作剧记录；
  - 老板友善回应并介绍银鳞龙嗜酒的弱点。

### 样例回合 2：搞恶作剧（验证 PowerContext 记忆写入）
- **输入**：`（恶作剧）趁老板转身，偷偷往他的招牌麦酒桶里倒了一勺辣椒粉。`
- **预期表现**：
  - 老板发现麦酒变辣，触发记仇反应；
  - `node_powercontext_capture` 将恶作剧写入 `scope_tavern_player_01` 的 `grudges` 账本，好感度下降 35 点。

### 样例回合 3：开启新会话再次光顾（验证 PowerContext 跨会话记忆复用与剧情蝴蝶效应）
- **操作**：在 Dify 中点击「新建对话（New Chat）」，保持 `player_scope = scope_tavern_player_01`。
- **输入**：`嘿巴恩，我隔了两天又来喝酒啦！今天酒馆有什么新委托？`
- **预期表现**：
  - `node_powercontext_recall` 召回上一会话的辣椒粉恶作剧记录（引用 `src_002`）；
  - 老板立刻翻旧账、宣布酒价翻三倍（15银币），并結合 `lore_01` + `lore_03` 布置专属赎罪任务：带着被加了辣椒粉的麦酒去迷雾森林灌醉银鳞龙，找回铁砧徽章。
